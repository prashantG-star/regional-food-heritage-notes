# 🌾 भारतीय खाद्यसंस्कृती आणि स्थानिक पदार्थ ज्ञानकोश

अन्न हे केवळ चव नसून संस्कृती, ऋतू आणि आठवणींचा ठेवा आहे. पारंपरिक पदार्थ, स्थानिक धान्य/घटक आणि ऋतुमानानुसार खाण्याच्या सवयींची नोंद ठेवणारा हा एक खुला संग्रह आहे.

## 📂 या संग्रहात काय आहे?
* **ऋतुनुसार आणि पारंपरिक नोंदी (`notes/seasonal-food-culture.md`):** वेगवेगळ्या ऋतूंत आणि सणांमध्ये तयार केल्या जाणाऱ्या पदार्थांची पार्श्वभूमी व महत्त्व.

## 🎯 उद्देश
नवीन पिढीला आणि जिज्ञासू वाचकांना आपल्या स्थानिक खाद्यसंस्कृतीची ओळख करून देणे आणि पारंपरिक ज्ञानाची जपणूक करणे.
